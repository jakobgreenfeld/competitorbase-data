# CompetitorBase data

Data published by [CompetitorBase](https://competitorbase.com), a competitor monitoring tool.

## competitor-monitoring-prices.json

Published prices of seven competitor monitoring tools (CompetitorBase, Competely, Visualping, CompetitorTrack, Unkover, Klue, Crayon), each read on the vendor's own pricing page on the date in `read_on`. Tools that do not publish a price say "not published".

Fields per tool: `name`, `domain`, `url`, `pricing_url`, `does`, `price`.

Rendered table: https://competitorbase.com/competitor-monitoring-cost
Ranked list: https://competitorbase.com/best-competitor-monitoring-tools
